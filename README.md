# UI 组件导航

**https://wuxie888.github.io/ui-components-nav/**

一个页面搜遍 Magic UI、Aceternity UI、cult-ui、Kokonut UI、motion-primitives、shadcn/ui 和 21st.dev 社区的 5,518 个 React / Tailwind 组件，覆盖 83 个分类；1,935 个可一键复制 AI 提示词（含源码、demo、依赖、集成步骤），其余跳转作者原地址。

- 左侧按来源 / 分类 / 许可证筛选，`/` 聚焦搜索，筛选状态写在网址里可直接分享
- 点卡片看详情：大预览、依赖、文件列表、查看代码
- 明暗主题、手机端适配

本站不托管组件本体，版权归各作者。若你是作者且不希望作品出现在此，提 issue 即删。
